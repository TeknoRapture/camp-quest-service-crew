# Reference Images

These images are visual references for Camp Quest: Service Crew.

## stony-glen-map.png

Use this as a loose visual reference for the camp layout. The game map does not need to exactly reproduce the image, but it should preserve recognizable camp areas where practical.

## beware-of-cliff-sign.png

Use this as the visual reference for the in-game “Beware of Cliff!” sign. The in-game version can be simplified, but it should clearly resemble this image.
